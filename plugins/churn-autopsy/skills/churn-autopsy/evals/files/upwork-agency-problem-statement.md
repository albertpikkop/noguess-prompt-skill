# 90-day problem statement (test fixture, written for testing this skill)

We run a small digital marketing agency. We manage paid ads for clients. In the last 90
days every client we signed has left. Churn is 100%.

is three people.

We are not able to figure out the root cause of this high churn. We think it may be
quality, or the client experience, or the reporting dashboard, but we are not sure. We
need to know what to fix.
